# Aperture for Android

Download **[Aperture.apk](./Aperture.apk)** and install it on a phone or emulator (Android 8.0+).

1. On your phone, open the APK from Files or Chrome.
2. Allow install from that source if Android asks.
3. Open **Aperture**, tap **Choose folder**, and pick a photo directory.

This is a debug-signed sideload build, not a Play Store release. GitHub Actions also attaches a fresh `Aperture.apk` to each workflow run.
